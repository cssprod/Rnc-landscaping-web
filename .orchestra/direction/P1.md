# P1 — "Bioluminescent Fir" (art-direction proposal)

**Pitch.** It's night on the Salish Sea coast. Firs stand black against a moving aurora, the cove's surf glows sea-glass where the waves break, fireflies drift in the understory and the moon lays a path across the water. Switch to light and the same DOM becomes a **misty Pacific dawn**: peach and honey wash, lilac Olympics, a sun rising behind the range, gold dew motes. The feeling is emotional and cinematic, with organic glow. It is living vector art, not photos, and it has no HUD, counters or stats.

Specimens: `/tmp/claude-0/-home-user-Rnc-landscaping-web/5110250c-2871-5a49-ba20-c506ac0ea22b/scratchpad/direction/P1/specimen-dark.html`, `/tmp/claude-0/-home-user-Rnc-landscaping-web/5110250c-2871-5a49-ba20-c506ac0ea22b/scratchpad/direction/P1/specimen-light.html`, generated by `/tmp/claude-0/-home-user-Rnc-landscaping-web/5110250c-2871-5a49-ba20-c506ac0ea22b/scratchpad/direction/P1/gen.mjs` from `palette.mjs` and `scene.mjs`. The contrast script is `contrast.mjs` and its output is `contrast-table.md`. Screenshots: `/tmp/claude-0/-home-user-Rnc-landscaping-web/5110250c-2871-5a49-ba20-c506ac0ea22b/scratchpad/direction/P1/p1-{dark,light}-{390,1440}-{static,motion}.png`. ## 3. Layout grammar
- **Rhythm.**
  - Sections use `padding-block: clamp(4rem, 2.667rem + 5.926vw, 8rem)` with a 1200 max, and the gutter is clamp(1rem…2.25rem).
  - Each section opens with a **numbered head**: a pill `01` in brand at 12% fill with a 30% ring, the label, and a 120px hairline fading from brand. Then an h2 (max 46rem) and a lede in ink-2.
  - Numbers run per page, as 01–n.
- **Bento.**
  - **Grid sizes:** 1 column, then 2 columns at 40em (the spotlight card spans both), then 4 columns at 64em with `grid-auto-rows:minmax(200px,auto)`.
  - **Recipe:** spotlight 2×2, tall 1×2, two 1×1 cells, wide 2×1, and a 2×1 solid "how we work". Gap 14px, radius 26 outer and 18 inner (concentric).
  - **Card anatomy:**
    - a living-art vignette on top that uses the same `--sc-*` vars as the hero, so cards change with the theme;
    - a body with a small numeral, the title and one sentence;
    - a 40px round "go" chip at the top right that fills brand on hover.
  - Cards are container-query reflow units. There are no stats and no counters in bento.
- **Glass vs solid (resolves the C3 tension).**
  - Real `backdrop-filter` glass is used **only where something moves or sits behind it**: the header capsule, the sticky bar, the hero secondary button, menus and sheets. That is ≤ 3 per mobile viewport.
  - **Content cards are "lit solid"**: opaque gradients with the glass rim, edge and sheen. They give the glass look with predictable contrast and no blur cost.
  - Under `prefers-reduced-transparency` or `prefers-contrast:more`, every glass element turns `bg-elevated` and the grain disappears.
- **Spec strip.**
  - A `<dl>` in 2 columns, then 4 from 40em, with 1px line rules. Separators are 1px gradients from brand down to transparent, a "glowing filament".
  - `dt` is ink-3 uppercase 12px and `dd` is ink 600.
  - It uses only content fields (service, area, clientType, duration). It never shows budgets, invented areas or invented counts. A placeholder-coloured "Sample" tag is mandatory on sample projects.
- **Deep bands:** the CTA band and footer stay **dark in both themes**. On a dawn page the band reads as a window into the night forest, which ties the two themes together.

## 5. The living landscape hero (one DOM, two worlds)
**Geometry.**
- Every land layer is its **own outer `<svg>`**, sharing `viewBox 0 0 1600 400` with `xMidYMax slice`, inside a land box (`width:max(100%,1360px); aspect-ratio:4/1`), so all layers align.
- Mobile shows the centre crop (x≈570–1030): mountains, the cove, the surf glow and fireflies.
- The moon and stars use `overflow:visible` so they rise into the sky above the box.
- **Rule:** hero copy padding-bottom is `land-h × .9`. Text sits only on sky and aurora, which the contrast table covers, never on land.

**Layer stack, back to front.**

| Layer | Night | Dawn | Motion |
|---|---|---|---|
| sky (div gradient) | fir-black → teal | mist blue → peach | static |
| aurora wrap (2 divs) | moss/sea/camas ellipses plus striated rays (masked) | peach/honey/lilac wash plus light shafts | T2: one wrapper transform, 38 s |
| stars A/B | 2 path layers of round-cap dots | opacity 0 | T2: A twinkles 7 s; B static |
| moon/sun | crescent plus earthshine plus halo | full disc, warm halo, `translate 0 30%` so it rises behind the Olympics | static |
| far range | Olympics with a moonlit rim | lilac with a pink rim | T1 rise |
| water plus moon column | deep teal | pearl | static |
| shimmer A/B | moon glints | gold glints | T2: cross-fade plus 10–14px slide, 5.5/7.5 s |
| mid headlands plus small firs | | | T1 rise |
| mist | sea-glass 10% | white 55% (fog bank) | T2: 70 s drift |

- **Theming:** the theme switch changes only CSS custom properties (classes `.f-*`, `.s-*`, `.st-*` map to `--sc-*`), so there is no second DOM.
- **Chip:** an "Illustration" chip sits bottom right and is aria-hidden like the whole scene.
- **LCP:** the H1 is the LCP element and is never animated. Entrance rises animate only the land layers (`translate`, ≤ 1.8 s).
- **Gating, per 95-motion:** loops attach only under `html.js[data-alive]:not([data-motion=off])`, where `data-alive` is set after load plus idle.
  - The `--play` play-state is paused when the scene is off-screen (IntersectionObserver) or the tab is hidden.
  - Under reduced motion, with no stored "on", there is no animation at all. With no JS there is no ambient motion.
  - Loops use only transform and opacity, on layer boxes only.
- **Budget:** 14.7 KB raw / 4.6 KB gz (budget 16 KB raw). The tricks:
  - 13 pre-sized fir symbols placed with `x/y`;
  - stars as zero-length round-cap strokes;
  - the surf glow as one path drawn three times via `<use>`.

## 6. Other rules for builders
- **Sticky Call / Free-quote bar:** hidden (`visibility:hidden`) while the hero CTAs are in view, so the first mobile viewport shows the scene. It appears after that. With no JS it is always shown.
- **Toggles:** the moon icon is "Dark theme" and the spark icon is "Animations". Both are 44×44, `aria-pressed`, with visually hidden names. The pressed state is a brand tint plus a moss glow.
- **Light-theme hero ink:** use ink, not ink-2, for anything that could approach the far range (4.32 fails for ink-2).
- **Light-theme vignette strokes:** these must use brand-2, not `--sc-surf` (white on pale sky is invisible). Fixed in the specimen with `.s-irr`.
